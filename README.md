# Publications to Python
I use this repository to convert academic publications I read into Python. To increase both my understanding of the material discussed and my programming abilities.

LLM tools are used as part of the infrastructure of this repository and the [blog](lux-ferrata.org) that it supports. But, like the blogs prose all code written in these files is written by me. With LLM's being used to check for correctness, accuracy, and style.
